# Integrations

Print Vault can pull models and files from external platforms. Each
integration is optional and degrades to off when unconfigured.

- [Onshape](/integrations/onshape) — import CAD models via "Sign in with
  Onshape", sync when the document changes, or pin a version snapshot.
  Requires an OAuth app (instance-wide environment variables).
- [Bambu Cloud](/integrations/bambu-cloud) — a per-user account connection
  that unlocks MakerWorld file downloads and collection import.
- [MakerWorld & Printables](/integrations/makerworld-printables) — import
  models by URL, sync them with their source later, and bulk-import whole
  MakerWorld collections.
